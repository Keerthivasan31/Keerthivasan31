## 🚀 Featured DevOps Project

### Food Delivery Microservices Platform on AWS

> An end-to-end cloud and DevOps project demonstrating containerized microservices, automated delivery, infrastructure as code, monitoring, storage, security, and event-driven notifications.

<div align="center">

`Route 53` → `ACM / HTTPS` → `Application Load Balancer` → `ECS Fargate` → `Amazon RDS`

`Source Code` → `Jenkins` → `Docker Build` → `Amazon ECR` → `ECS Deployment` → `CloudWatch`

</div>

- 🧩 **Architecture:** Five React/Vite frontends and five Node.js/Express microservices
- 📦 **Containers:** Built and stored 10 Docker images in Amazon ECR
- 🏗️ **Infrastructure as Code:** Provisioned AWS resources with reusable CloudFormation templates
- 🔁 **CI/CD:** Validated code, built images, pushed to ECR, deployed to ECS, and checked service stability through Jenkins
- 🗄️ **Data & Storage:** Used PostgreSQL on Amazon RDS and S3-backed menu image storage
- 🔔 **Events:** Implemented SNS-based order notifications
- 📈 **Operations:** Added CloudWatch monitoring, CloudTrail auditing, health checks, and ECS autoscaling
- 🔐 **Application Security:** Implemented JWT authentication and controlled AWS access with IAM
