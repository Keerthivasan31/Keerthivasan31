## 🚀 Featured DevOps Project

### Food Delivery Microservices Platform on AWS

A cloud-native food delivery platform designed to demonstrate end-to-end AWS and DevOps practices.

**Architecture:** Route 53 → ACM/HTTPS → Application Load Balancer → ECS Fargate → PostgreSQL on Amazon RDS

- Containerized five React/Vite frontends and five Node.js/Express microservices with Docker
- Stored and managed application images in Amazon ECR
- Provisioned AWS infrastructure with reusable CloudFormation templates
- Built a Jenkins pipeline to validate code, build and push 10 images, deploy services, and verify ECS stability
- Added S3-backed menu image storage and SNS-based order notifications
- Configured CloudWatch monitoring, CloudTrail auditing, and ECS service autoscaling
- Implemented PostgreSQL persistence, REST APIs, and JWT-based authentication

**Core technologies:** `AWS` `Docker` `ECS Fargate` `ECR` `CloudFormation` `Jenkins` `RDS PostgreSQL` `S3` `SNS` `CloudWatch`
